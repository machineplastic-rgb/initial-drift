# Initial Drift · 峠

Juego de derrapes en el navegador: puerto de montaña de noche, de día, nublado o con lluvia, seis pilotos con seis coches, modo historia en viñetas y garaje con ficha técnica y mejoras.

**Jugar:** https://machineplastic-rgb.github.io/initial-drift/

## Controles

- **↑ / W** acelerar · **↓ / S** frenar · **← → / A D** girar
- **Espacio** freno de mano (derrape) · **Shift** nitro
- **P / Esc** pausa · **R** recolocar · **C** cámara · **T** trama sí/no · **M** sonido
- En el móvil: botones en pantalla y aceleración automática.

Derrapa para sumar puntos y cargar el nitro. Cuanto más largo el derrape, más sube el combo.

Hecho con Three.js. Coches, pista, música y efectos generados por código.
